# CLAUDE.md

## Project Description
This is the documentation for the dashboard project.

## Setup Instructions
To set up the project, follow these steps:
1. Clone the repository.
2. Install dependencies using npm or yarn.
3. Start the development server.

## Key Components
- **Frontend:** React components for the user interface.
- **Backend:** Node.js API for handling requests.
- **Database:** MongoDB for storing data.

## Important Notes
- The Department Access Control list is no longer needed. Only the checkbar where managers can grant access to workers is required.
